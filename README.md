# Presupuesto Mensual

App fullstack con Next.js para manejar presupuestos de casa.

## Requisitos

- Node.js 18+
- npm o yarn

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

Luego abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## Build

```bash
npm run build
npm run start
```

## Estructura

- `/app` - Next.js App Router (páginas y API routes)
- `/lib` - Funciones compartidas (API, database)
- `/presupuesto.db` - Base de datos SQLite (se crea automáticamente)
